# New Two-Path Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the setup wizard with a three-button Welcome and two paths — "What will my build get?" (enter parts → game-search performance estimate) and "Build for a game" (game + target FPS + budget → generated build) — with the 3D view only on Summary.

**Architecture:** A new pure module `src/lib/gameTargetBuilder.js` answers one game/resolution/preset cell (`fpsFor`) and optimises a build for it (`buildForGame`), reusing `autoBuild` to fill the non-CPU/GPU parts cheaply. A shared `GameSettingsFields` control (native `<datalist>` search + `<select>`) feeds both the Path 1 estimator (top of the Performance tab) and the new lazy `TargetScreen`. The store's `flow` loses `setup`, gains `target`, and gains a persisted `path` (`parts | game`) that drives a "Next" button through the builder tabs.

**Tech Stack:** React 19, Vite 8, Zustand 5 (persist), Tailwind 3, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-new-flow-design.md`

## Review Focus

1. **Typed game text that matches no game exactly** (partial name, wrong case) → no game is selected and the readout asks you to pick one from the list; nothing crashes. Pinned in Task 3.
2. **Target FPS or budget empty, zero or negative** → "Find builds" is disabled. Pinned in Task 4.
3. **A persisted `target.gameId` that is no longer in `perfGames.json`** (old localStorage) → treated as "no game chosen". Pinned in Task 3.
4. **Switching game while a preset key from the old game is stored** → falls back to the new game's heaviest preset, never `undefined`. Pinned in Task 2 (`findPreset`).
5. **A budget too small for any complete build** → "No complete build fits £X" and, if one exists, the cheapest build that hits the target. Pinned in Task 2 (`best === null`) and Task 4.

### Task 2: Game-target optimiser

**Files:**
- Create: `src/lib/gameTargetBuilder.js`
- Test: `src/tests/gameTargetBuilder.test.js`

**Interfaces:**
- Consumes: `estimateBuildPerformance` from `src/lib/perfEngine`, `autoBuild` from `src/lib/autoBuilder`, `presetsFor` from `src/lib/gamePresets`, `BUILD_PROFILES` from `src/lib/buildProfiles`.
- Produces:
  - `presetKey(preset) → string` — `${preset.id}|${preset.upscaling}`
  - `findPreset(game, key) → preset` — the preset with that key, else the game's last (heaviest) preset.
  - `fpsFor(parts, game, resolution, preset, model) → row | null` — the engine row for exactly that preset (fields used: `avgFps`, `lowFps`, `limitedBy`, `basis`, `bound`, `caveats`), or `null` when the build lacks a CPU/GPU.
  - `completeBuild(cpu, gpu, parts, resolution) → selection | null` — the cheapest sensible complete build around a CPU+GPU, or `null` if a category can't be filled.
  - `buildForGame({ game, preset, resolution, targetFps, budget, parts, model }) → { noData, unreachable, best, cheapestHit, fastest }` where each option is `{ parts, total, fps, lowFps, basis, bound }` or `null`.

Behaviour of `buildForGame`:
- `noData`: no CPU+GPU pair has an `avgFps` for this cell → everything else null/false.
- `best`: max FPS among complete builds with `total <= budget`; ties → higher CPU `perfScore`, then cheaper CPU+GPU, then ids. `null` if none fits.
- `cheapestHit`: only when `best` is null or `best.fps < targetFps`: the cheapest complete build with `fps >= targetFps` (any price). `null` if none.
- `unreachable`: no pair reaches `targetFps`.
- `fastest`: the highest-FPS complete build at any price (always set unless `noData`).

```js
// src/lib/gameTargetBuilder.js
import { estimateBuildPerformance } from './perfEngine'
import { autoBuild } from './autoBuilder'
import { presetsFor } from './gamePresets'
import { BUILD_PROFILES } from './buildProfiles'

const ESSENTIAL = ['cpu', 'gpu', 'motherboard', 'ram', 'cooler', 'case', 'storage', 'psu']
const NEEDS = BUILD_PROFILES.gaming.needs
const sumPrice = (sel) => Object.values(sel).reduce((s, p) => s + (p?.price ?? 0), 0)
const byId = (a, b) => (a < b ? -1 : a > b ? 1 : 0)

// A preset is a measurement condition, and two runs of one preset at different
// render scales are different measurements — so the key carries both halves.
export const presetKey = (p) => `${p.id}|${p.upscaling}`

// Heaviest preset as the fallback: the games list writes presets lowest tier
// first, and erring toward the heavier preset errs toward a LOWER frame rate.
export function findPreset(game, key) {
  const presets = presetsFor(game)
  return presets.find((p) => presetKey(p) === key) ?? presets[presets.length - 1]
}

export function fpsFor(parts, game, resolution, preset, model) {
  const r = estimateBuildPerformance({ parts, resolution, presetId: preset.id, model, games: [game] })
  return r?.games.find((x) => x.presetId === preset.id && x.upscaling === preset.upscaling) ?? null
}

// The cheapest SENSIBLE complete build around a CPU and GPU: enough memory and
// storage for a gaming profile, and a cooler rated for the chip, so nothing in
// it trips a build warning. autoBuild with a zero budget fills every empty
// category with its cheapest compatible part and sizes the PSU to the peak.
export function completeBuild(cpu, gpu, parts, resolution) {
  const catalog = parts.filter((p) =>
    (p.category !== 'ram' || (p.capacityGb ?? 0) >= NEEDS.ramGb) &&
    (p.category !== 'storage' || (p.capacityGb ?? 0) >= NEEDS.storageGb) &&
    (p.category !== 'cooler' || typeof p.specs?.ratedTdpW !== 'number' || p.specs.ratedTdpW >= (cpu.tdp ?? 0)))
  const build = autoBuild({ cpu, gpu }, 0, catalog, resolution)
  return ESSENTIAL.every((c) => build[c]) ? build : null
}

const option = (build, row) => ({
  parts: build, total: sumPrice(build), fps: row.avgFps, lowFps: row.lowFps, basis: row.basis, bound: row.bound,
})

export function buildForGame({ game, preset, resolution, targetFps, budget, parts, model }) {
  const cpus = parts.filter((p) => p.category === 'cpu' && !p.legacy)
  const gpus = parts.filter((p) => p.category === 'gpu' && !p.legacy)

  const pairs = []
  for (const cpu of cpus) {
    for (const gpu of gpus) {
      const row = fpsFor({ cpu, gpu }, game, resolution, preset, model)
      if (row?.avgFps != null) pairs.push({ cpu, gpu, row, core: cpu.price + gpu.price })
    }
  }
  if (pairs.length === 0) return { noData: true, unreachable: false, best: null, cheapestHit: null, fastest: null }

  // Completing a pair costs ~0.5 ms, so builds are made lazily and memoised;
  // the engine call per pair is the cheap part.
  const memo = new Map()
  const complete = (p) => {
    const k = `${p.cpu.id}|${p.gpu.id}`
    if (!memo.has(k)) memo.set(k, completeBuild(p.cpu, p.gpu, parts, resolution))
    return memo.get(k)
  }

  // Fastest first. On equal FPS the stronger CPU wins: most answers are
  // graphics-card ceilings that cannot see the CPU, and spending spare budget
  // on the chip is the sensible tie-break. Then cheaper, then ids.
  const fastFirst = [...pairs].sort((a, b) =>
    (b.row.avgFps - a.row.avgFps) || ((b.cpu.perfScore ?? 0) - (a.cpu.perfScore ?? 0)) ||
    (a.core - b.core) || byId(a.cpu.id, b.cpu.id) || byId(a.gpu.id, b.gpu.id))

  let fastest = null
  for (const p of fastFirst) {
    const b = complete(p)
    if (b) { fastest = option(b, p.row); break }
  }

  // ponytail: a linear walk down the FPS ranking; worst case completes every
  // pair (~2 s) when the budget is below every complete build. Add a per-CPU
  // platform floor to the `core` bound if that ever shows up in use.
  let best = null
  for (const p of fastFirst) {
    if (p.core > budget) continue
    const b = complete(p)
    if (b && sumPrice(b) <= budget) { best = option(b, p.row); break }
  }

  const unreachable = !pairs.some((p) => p.row.avgFps >= targetFps)

  let cheapestHit = null
  if (!unreachable && !(best && best.fps >= targetFps)) {
    const cheapFirst = pairs.filter((p) => p.row.avgFps >= targetFps).sort((a, b) =>
      (a.core - b.core) || (b.row.avgFps - a.row.avgFps) || byId(a.cpu.id, b.cpu.id) || byId(a.gpu.id, b.gpu.id))
    for (const p of cheapFirst) {
      // CPU + GPU alone already costs more than the cheapest whole build found.
      if (cheapestHit && p.core >= cheapestHit.total) break
      const b = complete(p)
      if (!b) continue
      const t = sumPrice(b)
      if (!cheapestHit || t < cheapestHit.total) cheapestHit = option(b, p.row)
    }
  }

  return { noData: false, unreachable, best, cheapestHit, fastest }
}
```

// src/components/GameSettingsFields.jsx
import { useState } from 'react'
import useBuilderStore from '../store/useBuilderStore'
import perfGames from '../data/perfGames.json'
import { findPreset, presetKey } from '../lib/gameTargetBuilder'
import { presetsFor } from '../lib/gamePresets'
import ResolutionPicker from './performance/ResolutionPicker'

export const gameById = (id) => perfGames.find((g) => g.id === id) ?? null

// A native <datalist>: the browser does the searching and the list, and a typed
// name only counts once it matches a game exactly — partial text selects nothing.
export default function GameSettingsFields() {
  const target = useBuilderStore((s) => s.target)
  const setTarget = useBuilderStore((s) => s.setTarget)
  const resolution = useBuilderStore((s) => s.resolution)
  const setResolution = useBuilderStore((s) => s.setResolution)
  const game = gameById(target.gameId)
  const [text, setText] = useState(game?.name ?? '')

  function onGameText(value) {
    setText(value)
    const match = perfGames.find((g) => g.name.toLowerCase() === value.trim().toLowerCase())
    if ((match?.id ?? null) !== target.gameId) setTarget({ gameId: match?.id ?? null, presetKey: null })
  }

  return (
    <div className="flex flex-wrap items-end gap-3">
      <label className="flex flex-col gap-1 text-xs text-muted">
        Game
        <input
          type="search" list="game-list" value={text} placeholder="Search games"
          onChange={(e) => onGameText(e.target.value)}
          className="rounded-lg border border-line bg-surface px-3 py-1.5 text-sm text-ink"
        />
        <datalist id="game-list">
          {perfGames.map((g) => <option key={g.id} value={g.name} />)}
        </datalist>
      </label>
      {game && (
        <label className="flex flex-col gap-1 text-xs text-muted">
          Graphics setting
          <select
            value={presetKey(findPreset(game, target.presetKey))}
            onChange={(e) => setTarget({ presetKey: e.target.value })}
            className="rounded-lg border border-line bg-surface px-3 py-1.5 text-sm text-ink"
          >
            {presetsFor(game).map((p) => <option key={presetKey(p)} value={presetKey(p)}>{p.label}</option>)}
          </select>
        </label>
      )}
      <ResolutionPicker value={resolution} onChange={setResolution} />
    </div>
  )
}

function BuildOption({ title, option, onUse }) {
  return (
    <section className={`${PANEL} p-4`}>
      <h2 className="text-base text-ink">{title}</h2>
      <p className={`${TELEMETRY} text-2xl text-ink`}>{fpsText(option)} · £{option.total.toFixed(0)}</p>
      <ul className="mt-2 text-xs text-muted">
        {CATEGORIES.filter((c) => option.parts[c.id]).map((c) => (
          <li key={c.id}>{c.label}: {option.parts[c.id].name}</li>
        ))}
      </ul>
      <button onClick={onUse} className={`mt-3 ${BTN_PRIMARY} text-sm px-4 py-2 rounded-lg`}>Use this build</button>
    </section>
  )

export default function TargetScreen() {
  const target = useBuilderStore((s) => s.target)
  const setTarget = useBuilderStore((s) => s.setTarget)
  const storeBudget = useBuilderStore((s) => s.budget)
  const resolution = useBuilderStore((s) => s.resolution)
  const parts = useCatalogStore((s) => s.parts)

    useBuilderStore.getState().setBudget(budgetNum)
    setResult({
      budget: budgetNum, fps: fpsNum, game,
      ...buildForGame({ game, preset: findPreset(game, target.presetKey), resolution,
                        targetFps: fpsNum, budget: budgetNum, parts, model: perfModel }),
    })
  }

  function use(option) {
    const s = useBuilderStore.getState()
    s.setBuild(option.parts)
    s.setPath('game')
    s.setFlow('builder', 'peripherals')

          Budget (£)
          <input type="number" min="1" value={budget} onChange={(e) => setBudgetText(e.target.value)}
                 className="w-32 rounded-lg border border-line bg-surface px-3 py-1.5 text-sm text-ink" />
        </label>
        <button onClick={find} disabled={!ready}
                className={`${BTN_PRIMARY} text-sm px-4 py-2 rounded-lg disabled:opacity-40 disabled:cursor-not-allowed`}>
          Find builds
        </button>
      </div>

      {result && (
        <div className="mt-6 flex flex-col gap-3">

                </p>
              )}
            </>
          )}
        </div>
      )}
    </div>

```jsx
// src/components/NextStep.jsx
import { ArrowRight } from 'lucide-react'
import useBuilderStore from '../store/useBuilderStore'
import { VIEWS } from '../hooks/useHashView'
import { BTN_PRIMARY } from '../lib/uiTokens'

// A game-target build arrives already chosen, so its steps skip Build and
// Performance; both tabs stay reachable from the tab bar.
export const stepsFor = (path) => (path === 'game' ? ['peripherals', 'summary'] : VIEWS)

export default function NextStep({ view, onChange }) {
  const path = useBuilderStore((s) => s.path)
  const steps = stepsFor(path)
  const next = steps[steps.indexOf(view) + 1]
  if (!next) return null
  return (
    <div className="relative z-10 flex justify-end w-full max-w-2xl lg:max-w-[1760px] mx-auto px-4 sm:px-6 lg:px-10 2xl:px-14 pb-6">
      <button onClick={() => onChange(next)}
              className={`${BTN_PRIMARY} text-sm px-5 py-2.5 rounded-lg capitalize inline-flex items-center gap-1.5`}>
        Next: {next} <ArrowRight size={14} aria-hidden="true" />
      </button>
    </div>
  )
}
```

(`steps.indexOf(view)` is −1 for a view off the path, so `next` is the path's first step.)

// e2e/helpers.js — replace generateBuild
// The game-target path is the shortest route to a full build. It ends on the
// Summary tab, where the 3D view, the score and the parts list live.
export async function generateBuild(page, { budget = '1600' } = {}) {
  await page.goto('/')
  await page.getByRole('button', { name: /build for a game/i }).click()
  await page.getByRole('combobox', { name: 'Game' }).fill('Fortnite')
  await page.getByRole('spinbutton', { name: /target fps/i }).fill('60')
  await page.getByRole('spinbutton', { name: /budget/i }).fill(budget)
  await page.getByRole('button', { name: /find builds/i }).click()
  await page.getByRole('button', { name: /use this build/i }).first().click()
  await expect(page).toHaveURL(/#peripherals/)
  await openTab(page, 'summary')
  await expect(page.getByText('/100')).toBeVisible()
}
